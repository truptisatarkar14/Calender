🗓️ Mini Calendar Project

A simple and interactive Mini Calendar built using HTML, CSS, and JavaScript. This project displays the current day, date, month, and year dynamically, helping users to view real-time calendar details in a clean and modern UI.

🚀 Features

 📅 Displays the current date, month, and year

⏰ Updates automatically based on system date

🎨 Beautiful and responsive UI using HTML5 and CSS3

⚡ Dynamic functionality using Vanilla JavaScript

💻 Lightweight and easy to integrate into any web page

🛠️ Technologies Used

HTML5 – Structure of the calendar

CSS3 – Styling and layout

JavaScript (ES6) – Logic for dynamic date and time
